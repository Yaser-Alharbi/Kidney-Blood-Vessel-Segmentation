Computational pathology

Stain-robust blood-vessel segmentation in kidney histology

Labs stain tissue with different strengths, so a model trained on one lab's slides can lose accuracy on another's. A U-Net with a ResNet-34 encoder, outlining blood vessels in PAS-stained kidney tiles, is trained four ways that differ only in stain handling: HED augmentation varies each stain's strength during training, and Macenko normalisation maps every tile to one reference stain. Each is tested on slides it never saw.

Limitations

  • Training uses a single slide, which limits how much stain diversity the model can learn from.
  • Test labels are model-generated, so test Dice supports comparing recipes, not absolute accuracy.
  • Absolute Dice is low because vessels are small and sparse, about 4.5% of pixels; the claim is the relative gain.
  • The example tiles were picked for large differences between the baseline and HED and are not typical.
  • Validation Dice also selects the checkpoint, so validation estimates are optimistically biased.
  • The PAS reference stain is fitted on the single training slide and inherits its stain.
  • Next: train on more than one slide and fit the reference across slides.
